
# SaaS Productivity Tool Backend

## Features
- MongoDB Connection using Mongoose
- Well-defined Mongoose Schema
- Mongoose Model
- Full CRUD Operations
- Error Handling Middleware
- REST API using Express

---

## Installation

npm install

---

## Run Server

npm run dev

---

## Environment Variables

PORT=7000
MONGO_URI=mongodb://127.0.0.1:27017/productivityDB

---

## API Endpoints

GET /api/tasks
POST /api/tasks
GET /api/tasks/:id
PUT /api/tasks/:id
DELETE /api/tasks/:id
